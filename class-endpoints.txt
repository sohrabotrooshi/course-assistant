Notes for agents

Endpoint routing: Port 9000 is reserved exclusively for agentic use with Hermes. Do not use port 9000 for basic LLM/VLM tasks such as classification, chat, or general text/vision processing; use port 9001 for those tasks.

Consult each model's Hugging Face page and the relevant server documentation for request formats, model identifiers, templates, and supported parameters.

- vLLM (9000–9005): https://docs.vllm.ai/en/latest/
- vLLM-Omni (9006 and 9009): https://docs.vllm.ai/projects/vllm-omni/en/latest/
- ACE-Step (9007): Uses an asynchronous music-generation API: submit a task, poll its status, then download the audio. Documentation: https://github.com/ace-step/ACE-Step-1.5/blob/main/docs/en/API.md
- Chatterbox (9008): Custom FastAPI wrapper for Chatterbox Multilingual V3. Use POST /v1/audio/speech with input text and request model ID "chatterbox-v3"; language_id selects the language (default: "en"). Supports the model's built-in default voice, saved voices via /v1/voices, and voice cloning using base64 ref_audio or multipart reference uploads to /v1/audio/speech/upload. Returns a complete audio file (MP3 by default). API docs: http://dobolyi.com:9008/docs; request schema: http://dobolyi.com:9008/openapi.json
- Intern Decision (9010): Custom FastAPI wrapper for Intern-Decision-4B. Send POST /v1/decisions (alias /v1/jev) with state, a questions object containing named choice, score, or noul (yes/no) questions, and optional images encoded as base64 upload objects. Returns JSON with per-question decisions and probabilities. Use its decision request schema rather than a chat-completions messages payload. Request examples: http://dobolyi.com:9010/examples; API docs: http://dobolyi.com:9010/docs
